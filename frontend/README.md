# Aeon's End Card Scanner - Frontend

This is the React 19 + TypeScript + Vite single-page application for the Aeon's End Supply Card Scanner.

For full project documentation, architecture, API reference, and deployment instructions, see the root [README.md](../README.md).

## Development

```bash
# Install dependencies
npm install

# Start Vite dev server with API proxy
npm run dev

# TypeScript type check and production build
npm run build

# Code linting
npm run lint
```
